# AgentTelemetry Document Map

`AgentTelemetry/` is a code repository first, so the root layout remains stable for development. Supplemental research and submission material is grouped rather than left as loose root-level notes.

## Start Here

- `../README.md`: public project overview and API entry point.
- `../paper/README.md`: publication and manuscript map.
- `../otep/README.md`: semantic-conventions proposal and review history map.
- `../PUBLISHING.md`: PyPI release workflow.

## Folder Roles

- `../benchmarks/`: benchmark scripts and summary TSV outputs.
- `../blog/`: announcement and outward-facing writing.
- `../examples/`: usage examples and experiment trace samples.
- `../experiments/`: research experiments and evaluation scripts.
- `../paper/`: conference manuscripts plus supporting publication material.
- `../otep/`: OpenTelemetry proposal material, submission package, reviews, and planning history.

## Consolidation Notes

- Paper support documents were moved under `paper/supporting/`.
- OTEP submission artifacts were grouped under `otep/submission/`.
- Older OTEP review and planning material was moved under `otep/archive/`.
- Source, tests, packaging, and root development docs were intentionally left in place.
