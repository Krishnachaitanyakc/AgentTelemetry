# Trace Data Quality for LLM-Agent Observability (IEEE BigData 2026, BigD260)

- `submitted/BigD260_4648.pdf`: the paper as submitted to the IEEE BigData 2026
  main track (10 pages). It was not accepted there and was transferred to the
  AAI-BD 2026 workshop for revision.
- `reconstructed/main.tex`: LaTeX source rebuilt from the submitted PDF, because
  the original source was lost. Its text, tables, equations and references match
  the submitted PDF word for word. Line and page breaks differ slightly because
  tectonic does not support microtype font expansion.

Build with `tectonic reconstructed/main.tex`.
