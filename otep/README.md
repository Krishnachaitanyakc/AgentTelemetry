# OTel Proposal Materials

This folder contains semantic-conventions proposal work related to AgentTelemetry.

## Canonical Entry Points

- `agent-semantic-conventions.md`: main proposal background.
- `SUBMITTING_OTEP.md`: current guidance on the actual submission path.
- `submission/`: current submission package and PR text.

## Structure

- `submission/`
  - Current PR descriptions, proposal summaries, and patch material for the focused submission path.
- `archive/reviews/`
  - Cold reviews and reviewer-facing critique documents.
- `archive/planning/`
  - Earlier planning, reconnaissance, and superseded execution notes.
- `archive/monitoring/`
  - Monitoring/log output from prior review activity.
- `comments/`
  - Daily issue and PR notes.
- `research/`
  - Deep dives and synthesis documents supporting the proposal.

## Usage

- Start in `SUBMITTING_OTEP.md` to understand the current recommendation.
- Use `submission/` when preparing or refreshing the live PR.
- Use `archive/` only for historical context or reviewer-traceability.
