    --exclude='__pycache__' \
    --exclude='.DS_Store' \

## Experiments — what each one produced

All experiment scripts live in `experiments/`. Each writes to a same-named subdirectory under `results/`. To re-run, source `.env` for API keys first.

### Core overhead + scalability
- `experiments/overhead_percentiles.py` → `results/overhead_percentiles/` — per-span overhead (11–13 µs p50; cited by Middleware, ATC)
- `experiments/overhead_multirun_and_isolation.py` (added 2026-05-17) → `results/overhead_percentiles/{multirun_ci.json, batch_isolation.json}` — 270K-span replication + DELEGATION tail latency isolation (cited by ATC round 5+)
- `experiments/scalability_stress_test.py` → `results/scalability/` — 78,087 spans/s in-memory, 19,071 spans/s under 100-thread concurrency (cited by Middleware, ATC)
- `experiments/breaker_overhead_multirun.py` (added 2026-05-17) → `results/overhead_percentiles/breaker_multirun.json` — 100K-span circuit-breaker overhead with 95% CIs (+2.16 µs p50; cited by ATC)
- `experiments/circuit_breaker_demo.py` → `results/circuit_breaker_demo/`
- `experiments/statistical_rigor.py` → `results/statistical_rigor/` — paired statistical analysis

### SWE-bench corpora (THE centerpiece for AIware, ISSRE, Edge-Cloud, IEEE SW HC, NIER)
- `experiments/swebench_full_matrix.py` → `results/swebench_full/` — full 14×6×7×6 matrix (3,780 rows in `benchmarks/results_full.tsv`)
- `experiments/swebench_n60_opus_cli.py` → `results/swebench_n60_opus/` — N=60 Opus tier
